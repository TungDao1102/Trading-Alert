# Phase 07.1 Plan 01: Close B1 registry-cost binding hole — Summary

## One-liner

Fail-closed binding gate in `assemble()` makes parameter set + cost a verified pair (canonical-hash-to-hash comparison), hardening BKTS-02 reproducibility without altering published experiment IDs.

## What was built

### Gate helper (`src/backtest/binding.py`)

New module under the `src/backtest/` purity contract (stdlib + Decimal only, no float). Exports:

- `CostModelBindingMismatch(Exception)` — dedicated exception for assembly refusal (distinct from `ExperimentReproducibilityBroken` which means replay drift on an existing record).
- `assert_cost_model_binds_registry(parameter_set, cost_model) -> None` — builds `registry_slice = {k: parameter_set.params[k] for k in COST_KEYS}`, derives expected via `build_cost_model(registry_slice)`, compares `cost_model_hash` strings. Inequality raises `CostModelBindingMismatch` naming both hashes plus `strategy_id/parameter_set_id`. Absent slice keys propagate as bare `KeyError` from `build_cost_model` (fail closed, never silent defaults).

### Gate wiring (`src/backtest/experiment.py`)

Single-line insertion in `assemble()` between `load_parameter_set()` and `_universe_hash()`. The gate sits strictly before `identity_payload` construction so no record exists on the mismatch path. `identity_payload` dict and `ExperimentRecord` fields are byte-identical pre/post gate (D-04).

### Re-exports (`src/backtest/__init__.py`)

`CostModelBindingMismatch` and `assert_cost_model_binds_registry` added to the barrel with matching `__all__` entries.

### Registry v3 sets (INSERT-only, D-04)

- `params/trend-pullback/baseline-v3.toml` — 7-key candidate set mirroring `baseline-v2` non-cost params exactly (`minimum_rr = 2.0`, all Phase 5 D-05 additions). `partial_fill_fraction = 0.5` (fractional, dodges the whole-number trap per Pitfall 1).
- `params/breakout-retest/baseline-v3.toml` — same shape, Family B keys.

`baseline-v2` is never edited (D-04 one-way permanence).

### Gate test module (`tests/test_backtest_binding.py`)

- **Beh. 1** — match-case assemble succeeds through the gate; six-field identity tuple intact.
- **Beh. 2** — byte-stability regression: two assemble() calls with identical inputs yield identical `experiment_id` (D-04).

Mismatch refusal coverage (wrong fee rate, wrong `funding_treatment`, precision drift) lands in plan 07.1-02.

### Match fixture (`tests/fixtures/phase7.1/match/input.json`)

Golden binding match fixture with `parameter_set_id="baseline-v3"`, `strategy_id="trend-pullback"`, `strategy_version="v2.0.0"`, `run_type="CANDIDATE"`, and cost dict spellings matching the v3 TOML (`partial_fill_fraction: "0.5"`).

### Static guard extension (`tests/test_domain_no_float.py`)

`"src/backtest/binding.py"` appended to `SCANNED_FILES` — the AST no-float walker now covers the new module.

### Test migration (`tests/test_backtest_experiment.py`)

Per D-05, phase6 fixtures stay byte-identical (NOT regenerated), but tests that call `assemble()` migrate to `baseline-v3` (7-key set). Added `_v3_case_input()` helper that rebinds `parameter_set_id` and fixes `partial_fill_fraction` spelling. Updated `_assemble_gap_record` default, `_gap_simulator_inputs`, `test_cr06` breakout-retest variant, and `test_cr03b` simple-trend fixture rebinding.
