<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DB rows / Parquet / JSON files -> analytics | Untrusted data; every loader validates and counts rejects |
| analytics CLI -> operational database | Read path must not mutate; single guarded append |
| requested output path -> filesystem | Path traversal risk when writing reports containing account PnL |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-10-28 | Tampering | read path mutating operational tables | high | mitigate | Reader functions only build/execute Select; source tests assert no insert/update/delete outside build_append_stmt; appender refuses any event type but KILL_GATE_EVALUATION and uses ON CONFLICT DO NOTHING |
| T-10-29 | Tampering | path traversal on output directory | high | mitigate | confine_output_dir resolves and confines to data/reports; tests for .., absolute escape and symlink escape |
| T-10-30 | Tampering | malformed rows/JSON crashing or silently skewing the report | medium | mitigate | Rows converted inside try/except and counted as rejected; JSON loaders fail closed with typed errors naming only the key |
| T-10-31 | Information disclosure | secrets (DATABASE_URL) or request text in adapter errors/outputs | medium | mitigate | Errors carry key names and counts only; no connection strings or payload text are echoed |
| T-10-32 | Spoofing | family independence claimed by a free-text flag | medium | mitigate | Facts derived from the real registry, sheets and CANDIDATE experiments; unknown hashes reported, never guessed |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages installed (polars, sqlalchemy, psycopg already dependencies); any future install requires the legitimacy gate plus a blocking human checkpoint |
</threat_model>
