## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| journal/decision/reason text -> Markdown document | Untrusted text becomes document content read by operators and viewers |
| report -> operator | Wording can steer decisions; must stay descriptive and non-advisory |

| T-10-34 | Tampering | INSUFFICIENT_EDGE styled as error or favorability emphasis nudging manual override | medium | mitigate | Fixed calm sentences copied from UI-SPEC; no emphasis encodes favorability; PASSING_CANDIDATE sentence explicitly non-authorizing; golden pins wording |
