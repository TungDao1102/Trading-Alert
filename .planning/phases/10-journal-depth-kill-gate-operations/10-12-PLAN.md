| T-10-41 | Tampering | path traversal via --out-dir | high | mitigate | confine_output_dir on the resolved path; tests for .. and absolute escapes exit 1 with no file written; reports root is git-ignored data/reports |
| T-10-42 | Tampering | --record writing beyond KILL_GATE_EVALUATION or mutating tables from the report path | high | mitigate | Read path executes only Select (statement-kind test); --record uses the guarded append that refuses other event types and uses ON CONFLICT DO NOTHING; edge guard asserts the single Insert builder |
| T-10-43 | Repudiation | non-idempotent or duplicate terminal-outcome records | medium | mitigate | Content-hash event id; second identical --record prints the same id and inserts nothing (test) |
| T-10-44 | Information disclosure | DATABASE_URL or request text in outputs/errors | high | mitigate | DB errors reduced to exception type names; test greps stdout, stderr and both files for the URL string |
| T-10-45 | Tampering | ambient wall-clock or environment making outputs non-reproducible | medium | mitigate | --as-of injected; one clock read only when omitted (AST test); byte-identity test; no hostname/path in report content |
| T-10-46 | Elevation of privilege | CLI enabling live or clearing terminal state | high | mitigate | CLI imports no enablement code and writes no reset; guard tests assert no import of src.execution and no reset event type appended |
