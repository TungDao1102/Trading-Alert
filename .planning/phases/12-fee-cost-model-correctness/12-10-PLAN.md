Grid and expectations (planning-time analysis, independent arithmetic). Rates: fee_in 0.0005, slip_in 0.0001, fee_out 0.0005, slip_out 0.0003; guards 0.003 and 0.15; equity 10000 and 800, risk_rate 0.005. Zone is plus and minus 0.1 percent around the price; LONG stop = entry_max x (1 - w), SHORT stop = entry_min x (1 + w). Constraint snapshots: BTC tick 0.1 / step 0.001 / min_qty 0.001; ETH tick 0.01 / step 0.001 / min_qty 0.001; XRP tick 0.0001 / step 0.1 / min_qty 0.1; min_notional 5. Cost-to-risk for LONG is (0.0014 - 0.0008 w) / (w + 0.0014 - 0.0008 w) and for SHORT (0.0014 + 0.0008 w) / (w + 0.0014 + 0.0008 w) (of the edge price): at w = 0.008 LONG is about 0.14836 and SHORT about 0.14951 (both below 0.15); at w = 0.007 LONG is about 0.1661 (above). Worst case per fill p: LONG loss = (p - S) q + p q (fee_in + slip_in) + S q (fee_out + slip_out), SHORT loss = (S - p) q + the same fee and slippage terms; the loss is monotone in p and maximal at the adverse edge where it equals q x risk_per_unit. Old rate-sum formula (fee_in + fee_out + expected_slippage = 0.0011 added to a distance from the zone mid): BTC LONG w = 0.022 sizes 0.040 and loses 0.040 x 1403.0840 = 56.1234 at an edge fill, above 50; for XRP the rate-sum 0.0011 exceeds the true per-unit cost 0.000695, so the old formula over-stated cost there.
