## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| collect-list TOML file -> collector universe | An operator-editable file decides which symbols reach adapter calls, Parquet paths and SQL parameters |
| Binance public JSON (curl) -> proposer | Exchange-supplied symbol names and volumes decide the list content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-01 | Tampering | Symbol names from the collect list or exchange JSON used in partition paths and URLs (path traversal / injection) | high | mitigate | load_collect_list and propose_collect_list validate every symbol against ^[A-Z0-9]+USDT$ before use; explicit --universe values are validated too; tests cover "../BTCUSDT" and lowercase names |
| T-13-02 | Denial of service | Missing or broken list silently shrinking OI collection to the live-5 | high | mitigate | No fallback: collector exits 2 (healthcheck 1) with zero adapter calls; list must be a live-5 superset; test_missing_collect_list_refuses_start_without_live5_fallback |
| T-13-03 | Tampering | Non-TRADING symbol in the list journaling a gap row every tick | medium | mitigate | Proposer keeps only TRADING PERPETUAL USDT symbols (Pitfall 10); TRADIFI_PERPETUAL, SETTLING, PENDING_TRADING excluded by fixture tests |
| T-13-04 | Repudiation | Unrecorded provenance of the list | low | mitigate | chosen_on, selection_rule and a source comment with endpoint paths and fetch timestamp are written into the committed TOML |
| T-13-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed in this plan; stdlib tomllib only |
</threat_model>
