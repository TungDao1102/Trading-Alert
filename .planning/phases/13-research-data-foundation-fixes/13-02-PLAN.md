<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Exchange/archive kline rows -> quality gate -> immutable Parquet | External rows become permanent, hashed research data |
| Process crash / host interruption -> file system | A kill mid-write must not leave a readable partial file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-05 | Tampering | Partial or current UTC day published as immutable data (F-402) | high | mitigate | Effective end clamped to the current UTC day start; end-of-loop flush publishes only whole-window days or a terminal last day; partial days held back and counted; tests in test_backfill_closed_day.py |
| T-13-06 | Tampering | Torn Parquet file after an interrupted write (F-408) | high | mitigate | atomic_write_parquet: same-directory tmp, fsync, os.replace, tmp removed in finally; crash tests |
| T-13-07 | Tampering | Silent overwrite of a published partition through os.replace | high | mitigate | exists() check kept before replace and inside atomic_write_parquet; FileExistsError test proves original bytes unchanged |
| T-13-08 | Tampering | Silent Decimal rounding to scale 8 in hashed data | medium | mitigate | bad_decimals structural rejection for more than 8 fractional digits or non-finite values |
| T-13-09 | Denial of service | Transient Windows PermissionError on replace failing a long backfill | low | mitigate | Bounded retry (REPLACE_MAX_ATTEMPTS) then fail closed with the tmp removed |
| T-13-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed in this plan |
</threat_model>
