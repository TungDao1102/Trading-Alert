<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| data.binance.vision zip/CSV/.CHECKSUM -> archive parser -> quality gate -> immutable Parquet | Downloaded third-party files become permanent research data |
| S3 XML listing -> symbol names -> URLs and paths | Listing strings drive network requests and partition paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-18 | Tampering | Corrupted or tampered archive zip | high | mitigate | sha256 compared to .CHECKSUM (transport integrity), missing checksum fails closed, then the full check_batch gate; mismatch publishes nothing |
| T-13-19 | Denial of service | Zip bomb or oversized download | high | mitigate | Streamed byte cap MAX_ZIP_BYTES, ZipInfo.file_size cap MAX_CSV_BYTES, single member only, in-memory read, per-request timeout |
| T-13-20 | Tampering | Path traversal via zip member names or listing-derived symbols | high | mitigate | Exact expected member name required; SYMBOL_RE on every symbol before URL or path use; extractall never used |
| T-13-21 | Spoofing | TLS disabled or redirect to another host | medium | mitigate | httpx client verify=True, follow_redirects=False, fixed HTTPS base URLs |
| T-13-22 | Denial of service | Unbounded listing pages or oversized XML | medium | mitigate | MAX_LISTING_PAGES and MAX_LISTING_BYTES caps; ElementTree on capped bodies only |
| T-13-23 | Repudiation | Checksum mistaken for authenticity | low | accept | Documented as transport integrity only (shared origin); authenticity is not available from the archive; the gate and later sufficiency report provide the remaining checks |
| T-13-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed; httpx and respx are already declared and locked |
</threat_model>
