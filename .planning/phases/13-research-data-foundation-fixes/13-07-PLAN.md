## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| exchangeInfo (status, onboard, deliveryDate) -> window planner -> immutable Parquet extent | Exchange metadata decides which days become permanent data |
| CLI flags / manifest / collect list -> universe | Operator and repository inputs decide the fetched symbols |
| CLI -> PostgreSQL (DATABASE_URL) | Credentials pass through the process environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-29 | Tampering | Post-delivery synthetic flat bars published as real data | high | mitigate | Terminal cap at deliveryDate for non-TRADING symbols; DELIVERY_UNKNOWN gets no window; flat-bars fake-adapter test |
| T-13-30 | Tampering | Metadata text truncated or overflowing String(16) | medium | mitigate | Universe filter always passed; width guard raises and rolls back |
| T-13-31 | Information disclosure | DATABASE_URL or credentials printed on failure | medium | mitigate | Only exception type names are printed; URL read once and passed to the engine factory |
| T-13-32 | Denial of service | Weight budget exceeded, 418 IP ban | medium | mitigate | Sequential symbols and intervals, page_size 1000 (weight 5), default pace 0.25 s, existing bounded tenacity retry |
| T-13-33 | Tampering | Re-run double-publishing or crashing on an existing day | medium | mitigate | CursorStore per dataset plus latest-published-day floor; resume test |
| T-13-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed in this plan |
