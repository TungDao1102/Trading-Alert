## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Immutable Parquet store -> builder -> simulator/experiment record | Stored research data becomes backtest evidence identified by a hash |
| Caller arguments (symbol, interval, range, allow_gaps) -> file paths | Inputs choose which files are read |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-34 | Repudiation | Non-deterministic dataset identity making an experiment unreproducible | high | mitigate | Sorted posix relative paths plus per-file sha256 through sha256_hex; byte-equal and change-sensitivity tests |
| T-13-35 | Tampering | Silent padding or interpolation of missing bars | high | mitigate | gap_ranges_for_files single definition; CaseInputGapError unless explicitly allowed; allowed gaps recorded on the output |
| T-13-36 | Tampering | Lookahead through the current UTC day or live tick files | high | mitigate | as_of_day_utc input with range refusal; whole-day ranges only; no wall clock in the module (AST test) |
| T-13-37 | Tampering | Path traversal through symbol or interval arguments | medium | mitigate | Symbol regex and interval allow-list validated before any filesystem access |
| T-13-38 | Tampering | Float contaminating prices in the case input | medium | mitigate | Decimal-to-string conversion only; AST no-float test; sha256_hex rejects floats |
| T-13-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed; Polars and DuckDB are already pinned |
