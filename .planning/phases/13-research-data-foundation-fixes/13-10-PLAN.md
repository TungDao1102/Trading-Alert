## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-39 | Tampering | Half-written freeze (manifest FROZEN without witness or the reverse) | high | mitigate | Validate before writing, tmp + os.replace for both files, manifest restored if the witness write fails; UN-02 fails loudly on any half state |
| T-13-40 | Tampering | Freezing an unreviewed or edited proposal | high | mitigate | proposal_sha256 recomputed on load; --approve must equal it; explicit --freeze flag required |
| T-13-41 | Tampering | Survivorship bias through silently dropped delisted symbols | high | mitigate | All statuses plus archive-only candidates; unrankable and UNAVAILABLE symbols listed, never dropped; tests |

| T-13-43 | Tampering | Symbol names from the archive listing entering paths/URLs | medium | mitigate | SYMBOL_RE validation (13-05) before use |
