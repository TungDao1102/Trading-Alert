## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Third-party GitHub Actions -> CI runner | Action code runs with the job token and repository contents |
| Pull request content -> CI | Untrusted branch code runs in the job |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13.1-04 | Tampering | Floating action tags or tool versions (supply chain) | high | mitigate | 40-hex SHA pins with version comments, exact uv version, digest-pinned service image; test enforces |
| T-13.1-05 | Information disclosure | Resolved .env printed by compose config in CI logs | medium | mitigate | CI copies .env.example only and runs config quietly; no repository secrets referenced by ci.yml |
| T-13.1-06 | Elevation of privilege | Workflow token scope on pull requests | medium | mitigate | permissions contents: read; pull_request trigger (never pull_request_target) |
| T-13.1-07 | Denial of service | Gate bypassed by step-level failure suppression or vacuous skips | high | mitigate | Test bans suppression keys and or-true idioms; TRADING_CI_STRICT=1 turns infra skips into failures |
| T-13.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed; `uv sync --frozen` from the committed lock only |
</threat_model>
