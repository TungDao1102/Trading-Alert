## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public registries and apt mirrors -> image build | Base images, uv, rclone and the PGDG client enter the image |
| Host network -> PostgreSQL container | Only loopback is published |
| Build context -> image layers | Anything in the context can end up in a layer |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13.1-08 | Information disclosure | PostgreSQL port reachable from the internet (F-709) | high | mitigate | Publish 127.0.0.1 only; compose test asserts host_ip; runbook states ufw does not govern Docker ports |
| T-13.1-09 | Tampering | Floating base image tags (supply chain) | high | mitigate | tag@sha256 index digests for python, postgres, uv, rclone; no syntax directive; text test enforces |
| T-13.1-10 | Information disclosure | .env or data copied into the build context or an image layer | high | mitigate | .dockerignore excludes .env*, .git, data, logs, planning dirs; secrets only via runtime env_file |
| T-13.1-11 | Elevation of privilege | Container running as root or with writable mounts it does not need | medium | mitigate | USER 10001; backup mounts rawdata read-only; no docker socket mounted; ops image root only during apt |
| T-13.1-12 | Denial of service | Unbounded json logs fill the VPS disk; PID 1 ignores SIGTERM | medium | mitigate | json-file max-size and max-file on every service; init true and stop_grace_period |
| T-13.1-13 | Denial of service | Healthcheck can never pass (PATH python lacks the venv, F-705) | medium | mitigate | Exec-form venv interpreter; docker test runs the probe in the built image |
| T-13.1-14 | Tampering | PGDG apt key substituted in transit | medium | mitigate | Key fetched over https and its fingerprint checked during the build; build fails on mismatch |
| T-13.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | No Python packages added; image installs only from uv.lock with --frozen |
