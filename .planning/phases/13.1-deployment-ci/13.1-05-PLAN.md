<objective>
Write the shared shell library and `deploy/bootstrap.sh`, the one command that turns a fresh Ubuntu/Debian host into a hardened Docker host with the repo checked out and `.env` in place, testable on this Windows box through stubbed binaries and a path prefix. Add LF enforcement for everything Linux-bound.

Purpose: success criterion 4 (provider-neutral bootstrap) and the D-11 anti lock-out guarantee; OPS-06 (`.env` 0600) and OPS-02 (IP whitelist and no-withdrawal key in the operator checklist). Real-host effects (ufw, sshd reload, chrony, Docker apt repo) are only verifiable on a host and are listed as such in the runbook (plan 11).
Output: deploy/lib.sh, deploy/bootstrap.sh, .gitattributes rules, bash-driven tests and a script hygiene gate.

## Artifacts this phase produces (this plan)

- `deploy/lib.sh`: `log`, `warn`, `die`, `run` (prints `+ cmd` and skips execution under `DRY_RUN=1`), `require_cmd`, `read_os_release` (reads `${OS_RELEASE_FILE:-/etc/os-release}`), `p()` path helper prefixing absolute system paths with `${TRADING_ROOT_PREFIX:-}`, `write_if_changed` (atomic temp file plus rename, no-op when content is identical).
- `deploy/bootstrap.sh`: flags `--secrets-file PATH`, `--repo URL`, `--ref REF`, `--dir /opt/trading`, `--user trading`, `--authorized-keys PATH`, `--deploy-key PATH`, `--max-drift-ms 100`, `--dry-run`; functions per step; ends with `if [[ "${BASH_SOURCE[0]}" == "$0" ]]; then main "$@"; fi`.
- `.gitattributes`: keeps `tests/fixtures/phase10/render_golden/* -text` and adds `text eol=lf` rules for `deploy/**`, `*.sh`, `*.service`, `*.timer`, `Dockerfile`, `.dockerignore`, `docker-compose.yml`, `*.yml`, `.python-version`, `.env.example`, `tests/fixtures/cutover/**`.
- `tests/test_bootstrap.py`, `tests/test_deploy_scripts.py`.

Bash test harness (research Pattern 4): use `find_bash()` from tests/infra_helpers.py (skip, or fail under TRADING_CI_STRICT, when absent); write stubs and fixtures with `newline="\n"`; drive scripts through a tiny driver written into the temp dir that prepends its own `bin/` stub directory to PATH from inside bash (so Windows path conversion never matters); stubs append their argv to a log file and print canned output selected by env variables the test sets. POSIX file-mode assertions (`stat -c %a`) are skipped on win32 with the reason "NTFS cannot represent POSIX modes" and run in CI on Linux.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet -> VPS SSH | The only open port after bootstrap |
| Operator secrets file -> VPS filesystem | Secrets cross into the host once, into .env |
| Docker apt repository -> host packages | Package source for the container runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13.1-19 | Spoofing | Password or root SSH login still possible after hardening (PAM keyboard-interactive, drop-in precedence) | high | mitigate | 00- drop-in, KbdInteractiveAuthentication no, Include check, `sshd -T` assertion with rollback of the drop-in |
| T-13.1-20 | Denial of service | Operator locks themselves out (no key, firewall before allow) | high | mitigate | D-11 preflight key guard before any step; ufw allow of the effective port before enable; keep-session warning |
| T-13.1-21 | Information disclosure | .env readable by other users or echoed to the terminal | high | mitigate | install -m 0600 owner trading under umask 077; mode verified; values never printed; placeholder refusal |
| T-13.1-22 | Tampering | Docker packages from an unauthenticated source | medium | mitigate | Official repository over https with Signed-By keyring in deb822 form, exactly as Docker's current install docs |
| T-13.1-23 | Elevation of privilege | `trading` in the docker group is root-equivalent | low | accept | Single-operator host; documented in the checklist and runbook; no docker socket mounted into containers |
| T-13.1-24 | Tampering | Clock drift corrupts tick timestamps | medium | mitigate | chrony enabled, timesyncd disabled, waitsync plus drift bound (100 ms default) |
| T-13.1-25 | Denial of service | CRLF line endings break scripts on Linux | medium | mitigate | .gitattributes eol=lf for every Linux-bound file; CR-scan and bash -n tests |
| T-13.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed; host apt packages come only from distro and Docker repositories |
</threat_model>
