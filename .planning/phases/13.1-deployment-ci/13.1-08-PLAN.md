<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| VPS -> S3-compatible provider | The provider stores the backups and must see only ciphertext |
| Remote store -> restore path | Pulled objects are untrusted until verified |
| Environment (backup credentials) -> rclone subprocess | Secrets cross into a child process |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13.1-33 | Information disclosure | Provider or bucket reader sees research data or file names | high | mitigate | rclone crypt over the S3 remote encrypts contents and names client-side; key never on the provider side |
| T-13.1-34 | Denial of service | Wrong crypt key looks like an empty store; restore or retention misbehaves | high | mitigate | Sentinel decrypt-and-compare before every operation; empty listing and rclone exit 3 are errors; sentinel created only by --init-remote |
| T-13.1-35 | Tampering | Retention deletes the backups that matter (outage, clock, unparseable names) | high | mitigate | Pure function counting periods that have a snapshot; newest always kept; unparseable never deleted; deletion only after cryptcheck; 400-day oracle test |
| T-13.1-36 | Tampering | Attacker with bucket write access deletes or rolls back snapshots | medium | transfer | Provider-side object versioning or object lock is an operator control documented in the runbook; crypt gives integrity per file, manifest hashes verified on pull |
| T-13.1-37 | Information disclosure | Backup credentials in argv, logs or error text | high | mitigate | Credentials only in child env; argv asserted secret-free; stderr excerpts scrubbed; error messages name variables, not values |
| T-13.1-38 | Tampering | Remote Parquet history overwritten or deleted | high | mitigate | Copy with --immutable, never sync, move or delete under parquet/ |
| T-13.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | No packages are installed; rclone comes from the digest-pinned image |
</threat_model>
