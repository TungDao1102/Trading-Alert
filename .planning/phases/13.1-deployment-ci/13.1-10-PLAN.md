<objective>
Ship the Linux shell wrappers for backup, restore and the restore drill, the systemd timer that schedules backups, and the update/rollback script the runbook describes; then prove backup, drill and restore end to end with real containers (D-12, D-13, D-16).

Output: four deploy scripts, two systemd units, stub-driven script tests, and a docker-marked drill test.

## Artifacts this phase produces (this plan)

- `deploy/backup.sh [--init-remote] [--install-timer] [--dry-run]`: default runs `docker compose --profile ops run --rm backup /app/.venv/bin/python -m src.ops.backup scheduled`; `--init-remote` runs `backup --bundle-root data/backup/bundle` then `push --init-remote`; `--install-timer` (root) installs the units under `${TRADING_ROOT_PREFIX:-}/etc/systemd/system` with the checkout directory substituted, then `systemctl daemon-reload` and `systemctl enable --now trading-backup.timer`.
- `deploy/restore.sh [--snapshot ID] [--force] [--no-start] [--dry-run]`: `docker compose up -d --wait postgres`; `run --rm ops ... pull --dest data/backup/restore-<UTC ts>`; `run --rm ops ... restore --bundle-root <that dir> --parquet-target data/raw [--force]`; then `docker compose up -d` unless `--no-start`.
- `deploy/backup-drill.sh [--dry-run]`: `run --rm ops ... drill-remote --scratch-root data/backup/drill-<UTC ts>`.
- `deploy/update.sh (--ref REF | --rollback) [--skip-backup] [--dry-run]`: state in `.deploy/last-good.env` (GIT_SHA, APP_IMAGE_ID, OPS_IMAGE_ID); images re-tagged `trading-alert:rollback` and `trading-alert-ops:rollback` before the build.
- `deploy/systemd/trading-backup.service` (Type=oneshot, User=trading, WorkingDirectory substitution token replaced at install, ExecStart `/usr/bin/env bash <dir>/deploy/backup.sh`) and `deploy/systemd/trading-backup.timer` (OnCalendar `*-*-* 03:15:00 UTC`, Persistent=true, RandomizedDelaySec=5m).
- `.gitignore`: `.deploy/`.
- `tests/test_deploy_backup_scripts.py` (stubs), `tests/test_docker_backup_drill.py` (docker-marked).

All wrappers `cd` to the repository root, source deploy/lib.sh, honour `COMPOSE_PROJECT_NAME` and `TRADING_ENV_FILE` from the environment (that is how the tests run several projects from one checkout), and reject unknown flags with exit 2.
