---

## Sampling Rate

- **After every task commit:** the test files the task touched (each task's `<automated>` commands), plus `.venv/Scripts/python -m mypy src` when `src/` changed and `.venv/Scripts/python -m ruff check <changed files>`
- **After every plan wave:** the quick run command, ruff check, ruff format check, mypy src
- **Before `/gsd-verify-work`:** full suite, docker suite (pass or daemon/image skip only), static gates, then the remote CI run confirmed in plan 12 (every job green, docker tests passed with zero skips)
- **Max feedback latency:** 60 seconds per task (full suite only at wave and phase boundaries)
