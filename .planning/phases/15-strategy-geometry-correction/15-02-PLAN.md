## Interface contract (later plans build on these names)
- `RATIONALE_BASES: tuple[str, ...] = ("STRUCTURAL", "COST_GUARD", "DECISION", "EXPERIMENT", "PLACEHOLDER")`
- `@dataclass(frozen=True) class RationaleEntry: key: str; basis: str; value: str; text: str; ref: str | None`
- `load_rationale(path: Path) -> dict[str, RationaleEntry]` (reads the `rationale` top-level table of the set file; raises ValueError on a malformed entry)
- `check_rationale(path: Path) -> list[str]` (problems, sorted, empty when complete)
- `placeholder_keys(path: Path) -> tuple[str, ...]` (sorted keys whose basis is PLACEHOLDER)
- `class UnrationalizedParameterSet(Exception)` (message names the set and the offending keys)
- `pin_stream_epoch(*, strategy_id, parameter_set_id, opened_at_utc, cost_model=None, registry_root=None, allow_unrationalized: bool = False)`
