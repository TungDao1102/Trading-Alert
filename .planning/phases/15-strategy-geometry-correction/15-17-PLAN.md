## Design (the user's decision at checkpoint 15-17-01 plus Claude's discretion, recorded here)
- Wiring point: `run_paper_tick` is the only paper entry point under src/ (codegraph: callers are the package export and tests; the Phase 16 runtime will call it per tick). Putting the gate there gives `pin_stream_epoch` a real production caller now, and every future paper path inherits it.
- Gate position (per Reply 1, which asks for the refusal before any candle is read): the gate block sits at the very top of `run_paper_tick`. It reads strategy_id, strategy_version and parameter_set_id from case_input and parses now_utc (needed as opened_at_utc; it is not a candle), then runs load_parameter_set, the existing strategy_version check, pin_stream_epoch and the hash-equality check. Only after that block does the function read symbol and ttl and parse account_state, constraint_snapshot, cost_model, open_positions, daily_loss_quote, the warm-up candles (today `_parse_candle` at loop.py ~338-339) and feed_events, in their current order, then the unchanged `assert_sizing_costs_bind_registry` call. For an accepted set the outcome is byte-identical. Only error precedence moves: registry, version and gate errors now come before input-parse errors. The one raise-test in the paper test files (tests/test_paper_closed_candle.py ~177, CostModelBindingMismatch on a registered set) still raises after the gate.
- Refusal form: the tick raises `UnrationalizedParameterSet` at its top, before any candle is parsed or feed event read. This matches the two refusals `run_paper_tick` already raises at entry (strategy_version mismatch `ValueError`, `CostModelBindingMismatch`). A NO_TRADE record would need a new reason code, and D-27 adds no new `RejectionReason` member. Because nothing is evaluated before the check, a refusal can never leave a half-processed run.
- Allowlist shape (user Option B, exact identity): `PaperAllowlistEntry` is a frozen dataclass with six str fields in this order: strategy_id, parameter_set_id, parameter_set_hash (full 64 lowercase hex), purpose, approved_at (ISO date), basis (the user checkpoint and decision row that approved it). `PAPER_START_ALLOWLIST` is a module constant in src/paper/freeze.py typed as a tuple of those entries, value the empty tuple. A tuple of frozen dataclasses cannot be extended in place; rebinding is caught by the Task 3 AST guard. The check reads the module attribute at call time (no copy at import, no default-argument capture), so a test's monkeypatch is honored and the production value is what runs. Neither name is exported (`__all__`, src/paper/__init__.py).
- Pass decision: the strategy_id and parameter_set_id select candidate entries (lookup only, exact string equality; never a strategy family, a prefix or a version name). The only thing that admits a set is exact string equality between an entry's parameter_set_hash and the set's computed hash.
- Hash source of truth: the hash compared is the parameter_set_hash `pin_stream_epoch` computes from the parameter file itself through the registry parse path (`_load_parameter_set_with_root`: `_parse_and_validate` plus `_canonical_parameter_set_hash`, the same construction as `load_parameter_set`), and `run_paper_tick` requires it to equal `load_parameter_set(...).parameter_set_hash`. tests/fixtures/phase4/parameters.json is never read by src/; tests may cross-check against it.
- Rationale-table detection: a set has rationale tables when its TOML document (stdlib tomllib on the file bytes) has a top-level `rationale` key. An empty or malformed rationale table counts as present and goes to the full check (fail closed). The allowlist is consulted only when the key is absent; a set with the key always gets the full `check_rationale` plus `placeholder_keys` check, whatever the allowlist holds (D-27 unchanged).
- Empty allowlist is a valid state: no import-time validation, no log line, no warning. The refusal message for a set without rationale tables names the set and its hash and says "missing rationale tables" and "not in the approved allowlist"; with an empty allowlist it adds that the approved allowlist is empty (checkpoint 15-17-01, Option B), which is the decided safe state and not a system fault. "missing" also keeps tests/test_paper_freeze.py::test_pin_stream_epoch_refuses_set_without_rationale green without an edit.
- `pin_stream_epoch` is called WITHOUT `cost_model`: the strict 07.1 binding also compares `partial_fill_fraction`, which `assert_sizing_costs_bind_registry` deliberately excludes (its docstring: partial-fill fixtures set a value the registry does not pin). Adding the strict binding would be a second, new refusal path. The existing `assert_sizing_costs_bind_registry` check stays exactly as it is, so no fixture changes behavior.
- The gate runs on every tick (each tick re-loads the set from disk). It is not cached across calls: each tick must judge the file it actually loads. A changed file is also a REGISTRY_DIFF for the freeze monitor.
