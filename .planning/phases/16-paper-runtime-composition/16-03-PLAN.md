<objective>
Split the public market-data surface of `src/adapters/binance_usdm.py` into a new `src/adapters/binance_public.py` so the SHADOW runtime can read market data without ever constructing the order adapter (SC6: "in SHADOW the process loads no trade-capable API key and never constructs an order adapter", D-13, L-12 / D040).

Purpose: `BinanceUsdmAdapter` mixes public data (`klines`, `mark_klines`, `funding_rate`, `server_time`, `exchange_info`) with order methods (`place_entry`, `place_algo_protective`, `cancel_normal_order`, `cancel_algo_order`, `query_*`, `snapshot_*`, `get_position_mode`, `user_commission_rate`), and the paper supervisor and resync import `Kline` from it (research Pitfall P16). A module-level import ban therefore cannot work; a separate public class can. Planner choice (Claude's discretion, D-13 "state which"): split the public class out and later ban any reference to `BinanceUsdmAdapter` and `src.execution.manager` in the SHADOW module closure (plan 16-38).
Output: new public adapter module, delegation in the order adapter, tests.
</objective>
