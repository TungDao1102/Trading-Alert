<objective>
Build the exit-criteria evaluator (D-23; SC4 "the paper exit criteria are quantitative and pre-registered", F-023) and the requirement closure rule (SC9). The evaluator reads one exported evidence bundle, applies each criterion ratified in D061 item D (L-04) with the REV-01 coverage semantics, the REV-02/REV-18 freeze-continuity rule, the REV-17 derived 319.2 h and the REV-03 rule that test signals never run inside the soak, and prints PASS or FAIL per criterion with the evidence it read. It evaluates; it never changes a threshold; user-owned numbers (O-07: health silence and lateness, continuous-uncovered ceiling, freeze-tick grace) come only from the ratified runtime configuration.

The closure rule implements SC9 / D061 item J: PAPER-01 completes when SC1, SC2 and SC7 hold, PAPER-02 when SC3 and SC5 hold, PAPER-03 stays Pending (Phase 26), and nothing closes on fake-level evidence. Every evidence item carries a proof class taken from where it came from, never from a flag.

Purpose: the trial evaluation (plan 16-44) and the in-trial checks (plan 16-43) need one deterministic judge; the evidence bundle format defined here is what the exporter of plan 16-30 writes.
Output: bundle format and loader, evaluator, closure rule, CLI, tests.
</objective>
