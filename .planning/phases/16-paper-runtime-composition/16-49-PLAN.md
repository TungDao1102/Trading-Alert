Configure the real durable evidence destination the user chose at O-01 (D061 item A; REV-08) and prove the publish path with a fixture bundle. Because S3 Object Lock is a one-way door (G9, G10: once enabled it cannot be disabled; a COMPLIANCE retention cannot be shortened), the reversibility gate inserts a confirmation checkpoint immediately before the configuration step. For a destination without an irreversible setting the confirmation records that and the step is ordinary.

Output: preflight evidence, the user's confirmation record, the destination record.
</objective>
