## Method caveats (read first)

- Pages were read with the WebFetch tool, which passes the page through a small summarising model. A "quotation" below is the text that tool returned for the page. It is not guaranteed to be character-exact. Re-check any quote that a safety decision depends on.
- Status values: `CITED` = every sub-point of the item was read on the page. `CITED (partial)` = some sub-points were read, and the note lists the sub-points that stay UNVERIFIED. `UNVERIFIED` = the answer could not be read. `NOT ATTEMPTED` = not done.
- No HTTP error (403, 404, timeout) occurred. The failures were of two kinds: (1) a page returned the site landing page, or (2) a page loaded but did not contain the fact. Each failed URL was retried once. See the failure list at the end.
- No credentials were used. No repository file other than this one was changed.
