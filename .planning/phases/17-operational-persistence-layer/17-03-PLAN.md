Execution is not blocked on a human checkpoint.
- Tables (research draft, verbatim):
  - Signal: DETECTED -> NOTIFIED, SKIPPED_BUSY, EXPIRED, INVALIDATED; NOTIFIED -> VIEWED, APPROVED, SKIPPED_USER, SKIPPED_BUSY, EXPIRED, INVALIDATED; VIEWED -> APPROVED, SKIPPED_USER, SKIPPED_BUSY, EXPIRED, INVALIDATED; terminal APPROVED, SKIPPED_USER, SKIPPED_BUSY, EXPIRED, INVALIDATED.
  - TradePlan: READY -> APPROVAL_PENDING, EXPIRED, INVALIDATED, SUPERSEDED; APPROVAL_PENDING -> APPROVED, EXPIRED, INVALIDATED, SUPERSEDED; APPROVED -> EXPIRED, INVALIDATED; terminal EXPIRED, INVALIDATED, SUPERSEDED (APPROVED -> SUPERSEDED stays illegal; open point for the user).
  - Order: PLANNED -> SUBMITTING, CANCELED; SUBMITTING -> NEW, REJECTED, UNKNOWN, CANCELED; NEW -> PARTIALLY_FILLED, FILLED, CANCELED, EXPIRED, REJECTED, UNKNOWN; PARTIALLY_FILLED -> FILLED, CANCELED, EXPIRED, UNKNOWN; UNKNOWN -> NEW, PARTIALLY_FILLED, FILLED, CANCELED, EXPIRED, REJECTED (reconciliation only); terminal FILLED, CANCELED, EXPIRED, REJECTED.
  - Position: OPEN -> CLOSING, CLOSED, LIQUIDATION_REPORTED, UNKNOWN; CLOSING -> CLOSED, OPEN, UNKNOWN; LIQUIDATION_REPORTED -> CLOSED, UNKNOWN; UNKNOWN -> OPEN, CLOSING, CLOSED, LIQUIDATION_REPORTED (reconciliation only); terminal CLOSED.
  - Approval: PENDING -> APPROVED, SKIPPED, EXPIRED; terminal APPROVED, SKIPPED, EXPIRED.
  - ExecutionIntent: INTENDED -> SENT, UNKNOWN, REJECTED; SENT -> ACKED, REJECTED, UNKNOWN; UNKNOWN -> ACKED, REJECTED; terminal ACKED, REJECTED.
