## Decisions applied in this plan

- C10: extend SymbolFilters with optional trailing fields (no migration); absent filter = None in the adapter, UNKNOWN in the snapshot JSON.
- working_type is MARK_PRICE (the manager hard-codes it for the SL and WORKING_TYPE_VALUES in src/domain/registry.py admits only MARK_PRICE, D037); any other value raises ValueError.
- The snapshot module lives in src/execution and takes primitive inputs (ExchangeFilterExtras) so it never imports the adapter or the SDK; the caller (Phase 19/24) maps SymbolFilters fields; tests do the mapping explicitly.
- Staleness reuses the placement gate predicate (src/execution/gates.py: stale if age > ttl or age < 0) with constraint_snapshot_ttl_seconds from ParameterSet.params; re-sizing on stale is Phase 19.
