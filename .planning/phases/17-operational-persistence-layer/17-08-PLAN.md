<objective>
Deliver the PostgreSQL journal store every journal-first controller can use unchanged, with idempotent-by-id writes that refuse to drop a colliding different event, and document how the controllers behave when the journal is down.

## Decisions applied in this plan

- Conflict rule: on a primary-key conflict the store re-reads the row and compares event_type, entity_type, entity_id, correlation_id, the five linkage ids and payload_json; occurred_at_utc and created_at_utc are excluded because a redelivered callback carries a new delivery time but the same deterministic id and payload (plan 04).
- Protocol conformance is verified by mypy through a TYPE_CHECKING-only function in src/persistence/journal.py that assigns a PgJournalStore to each JournalLike type (enablement, safe_mode, sweeper) and to the callback JournalReceipt alias; no new Protocol is invented (D-02).
- F-702 (enablement.disable journals before flipping) is not fixed here (Phase 20); the test pins today's behavior so Phase 20 changes it deliberately.
