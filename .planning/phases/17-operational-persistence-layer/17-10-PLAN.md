## Decisions applied in this plan

- Unchanged status is an idempotent no-op in the repository (assert_transition raises on equal states by design, plan 03).
- Each method takes an optional keyword `tx` (a Session from OperationalDatabase.transaction()); when absent it opens its own transaction (D-03 composition with PgJournalStore.append).
- Fill ingestion is idempotent on uq_fills_order_trade with re-read comparison (Phase 18's stream will redeliver fills); a different fill under the same (order_id, exchange_trade_id) raises RowConflict.
- Transition side effects on timestamps: Signal INVALIDATED sets invalidated_at_utc; Order CANCELED sets canceled_at_utc; Position CLOSED sets closed_at_utc; Order and Position transitions update updated_at_utc; all from the injected now_utc.
