## Decisions applied in this plan

- Restart rule (D-14): INTENDED/SENT after restart become UNKNOWN before resolution; the 3-day window comes from Binance Query Order retention (research Pitfall 11) and is a keyword argument with that default, documented with its source.
- New SAFE_MODE reason UNRESOLVED_EXECUTION_INTENT is added to GLOSSARY 9.4 in the same change as the code (D031).
- The resolver is not wired into a live process (Phase 20/24); it is a tested function.
- Concurrency tests use threading with one engine, store and asyncio.run per thread, synchronized by threading.Barrier through a store wrapper that waits before consume.
