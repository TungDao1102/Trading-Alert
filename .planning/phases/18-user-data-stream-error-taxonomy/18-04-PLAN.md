## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process environment / key file -> credentials | Secrets enter the process here and must never leave through output |
| client configuration -> network | A wrong host sends signed requests or credentials to the wrong environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-09 | Elevation of privilege | REST on Demo with WebSocket or WS-API on mainnet (SDK lazy defaults), or a mutated base path | critical | mitigate | One factory builds all three configurations from one row; unrequested surfaces get an inert .invalid URL; assert_environment re-reads every surface before use; AST single-construction-site test; transport-level host test |
| T-18-10 | Information disclosure | API key, secret or signature in logs, exception text, structlog events or evidence | high | mitigate | register_runtime_secret on load; shape rules for signature and X-MBX-APIKEY; tests capture stdlib and structlog output; keys never taken from argv or from the repository |
| T-18-11 | Information disclosure | listenKey (an account-level credential) logged by the SDK or by the project | high | mitigate | Key-name masking, shape rules and runtime registration of the key on receipt (the adapter of plan 18-11 registers it); a captured SDK-style log line is scrubbed in a test |
| T-18-12 | Spoofing | Demo credentials used against mainnet or the reverse | high | mitigate | Separate CredentialSpec per environment, no cross-reading, refuse_if_present for the other spec, LIVE requires the enablement state to be enabled |
| T-18-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed or changed in this plan |
</threat_model>
