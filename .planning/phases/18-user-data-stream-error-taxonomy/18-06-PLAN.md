<objective>
Replace the one-element allow-list `_ACTIVE_ALGO_STATUSES = {"NEW"}` of `src/execution/manager.py` by a documented classification table of every ALGO_UPDATE status (D-07, G2-028): ACTIVE, TERMINAL_OK, TERMINAL_FAILED or UNKNOWN, with unseen values failing closed to UNKNOWN. The four rows that the research flagged as judgment calls are the user's recorded decision (plan 18-02); this plan implements them and proves the code equals the record.

Purpose: attach and adoption need a single definition of "protection confirmed"; the sweeper (and Phase 20's reconcile) need the class for diagnosis. The old behavior stays fail-closed: only a resting, untriggered stop counts.
Output: the classification module, the manager wiring, the sweeper's journaled class, the EXECUTION_SPEC class column, tests.

Out of scope: reconcile and sweeper DECISIONS driven by the class (Phase 20), the REST `algoStatus` vocabulary equality with the WebSocket `X` vocabulary (an assumption recorded in the research; the probe in plan 18-20 captures it).
</objective>
