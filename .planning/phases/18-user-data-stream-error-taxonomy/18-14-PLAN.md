## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket continuity -> trust in events | Any gap (reconnect, rotation, expiry, overflow) makes later events unverifiable until REST confirms the state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-18-39 | Tampering | events after a connection gap trusted without a REST snapshot, so a missed fill or cancel is invisible | critical | mitigate | Every gap sets UNKNOWN; events are held and delivered only after a successful snapshot, flagged after_gap; a failed snapshot leaves the stream UNKNOWN; the SDK resubscribing an old key is handled by re-keying and forgetting the old name |
| T-18-40 | Denial of service | reconnect storm, unbounded retry loops, or an immediate re-key and snapshot after a 429, causing an IP ban | high | mitigate | tenacity with the ratified attempt, delay and wait limits and an injected sleep; exhaustion stops and reports; request_resync is explicit; the shared gate makes the port refuse during a ban or pause and the supervisor wait out a pause and stop on a ban before every REST step (user amendment 2026-10-16); 418 or auth failures on listenKey calls stop further calls |
| T-18-41 | Tampering | stopping the supervisor closes the account's singleton listenKey under another consumer | medium | mitigate | stop requires an explicit close_listen_key argument with no default; the smoke and probe scripts never run beside a live supervisor on the same account (documented in plan 18-18) |
| T-18-42 | Spoofing | silence mistaken for a healthy or a dead stream | medium | mitigate | Liveness from ping, pong and keepalive recency only; event silence is never a staleness input; a ratified none disables the verdict explicitly |
| T-18-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed or changed in this plan |
</threat_model>
