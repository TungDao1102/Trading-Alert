Build the D055 / D-16 / G2-029 Demo probe and prove its case logic offline (D-15, D-17, D-18): a runner that walks the cases in the CONTEXT order of risk against a project-owned port, records every exchange answer as data, cleans up, writes one scrubbed evidence file, and in dry-run mode records the requests it would send. Output: `scripts/demo_probe.py`, the scripted fakes, and three test files.

Out of scope: running anything against Binance (plan 18-20), correcting the fake or the documents (plan 18-21), the direct-transport option (plan 18-19), the D055 decision (a user decision after the probe).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| probe script -> Binance Demo (orders, positions, cancels) | The tool opens and closes real Demo positions and orders |
| probe findings -> project decisions | A fact recorded here could be mistaken for a mainnet fact or used to choose a parameter or to close D055 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-18-51 | Elevation of privilege | the probe sending orders to mainnet, with a live key, or without the user's go-ahead | critical | mitigate | No host, key, secret or LIVE option; assert_environment before every call; refusal when LIVE credential variables exist; --execute needs a terminal and the exact phrase; the dry run reaches no mutating method; AST scans for the mainnet host and .env reads |
| T-18-52 | Tampering | orders or a position left open on the Demo account after a case or a crash | high | mitigate | Cleanup after every case in a finally path (cancel-all, reduce-only flatten), verified flat; CLEANUP_FAILED with the exact state and exit 1; account state recorded before and after |
| T-18-53 | Tampering | a Demo observation used to choose a trading parameter or to close D055 | high | mitigate | The label "demo-observed, not mainnet" and the sentence that D055 stays OPEN are required evidence fields checked by the schema; the script edits no decision file; plan 18-21 only drafts a row for the user |
| T-18-54 | Denial of service | probe calls extending an IP ban | high | mitigate | ProbeBanned aborts the run; no retry exists; remaining cases are recorded NOT_OBSERVED with the ban reason |
| T-18-55 | Tampering | orders larger than the owner approved | high | mitigate | The script refuses any quantity above the approved one or any notional above the approved cap before sending; validated in tests |
