<objective>
Build the safety envelope and the first slice of the D055 / D-16 / G2-029 Demo probe and prove them offline (D-15, D-17, D-18): a runner that walks a case registry against a project-owned port, records every exchange answer as data, cleans up, writes one scrubbed evidence file, records in dry-run mode the requests it would send, and refuses everything outside the guarded, bounded, confirmed Demo path. The runner also defines the time, sleep and wait contracts (an injected clock and sleep, the owner's wait timeouts, one wait helper, the handler signature) that the case handlers of plan 18-23 consume without changing them. This plan implements the four read-only not-found cases; the cases that send orders (duplicate algo id, id reuse, the D055 cases, the G2-029 additions, the optional cases) are the expansion in plan 18-23, built on this envelope. The live run is the blocking-human plan 18-20; plans 18-17 and 18-23 together make that run safe, bounded and checkable.

Purpose: the facts the probe records decide three open questions (the actual not-found and duplicate codes, whether an id can be reused after FILLED or CANCELED, and the -4509 family of D055) and let plan 18-21 correct `BinanceSemanticsFakeAdapter` from evidence. The probe never closes D055 and never chooses a model.
Output: `scripts/demo_probe.py`, the scripted fakes, and three test files.

Tracer note: Task 1 is the tracer (arguments, port, a first slice of cases, cleanup, evidence contract, dry run end to end). Task 2 completes the live path (guarded port, live rig, frame capture, verdict, CLI gates) before any case that sends an order exists, so the safety envelope is in place first.

Out of scope: running anything against Binance (plan 18-20), the cases that send orders (plan 18-23), correcting the fake (plan 18-21) or the documents (plan 18-25), the direct-transport option (plan 18-19), the D055 decision (a user decision after the probe).
