## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-18-59 | Information disclosure | the listenKey in the connection URL path leaking through aiohttp exceptions, logs or reprs (the redactor's listenKey= shape rule does not match a path segment) | high | mitigate | register_runtime_secret is the first statement of connect and rebuild, before the URL is built; errors are re-raised as ConnectionError without URL or key; the module logs event and exception type names only; a capture test with a failing loopback connection and an unregistered key at test start |
| T-18-60 | Tampering | connecting to a wrong host or with TLS verification disabled | high | mitigate | endpoint_guard (assert_endpoint_url over the environment row) runs before every connect; AST scan forbids ssl=False and verify_ssl; wss only |
| T-18-61 | Tampering | an unreviewed or substituted dependency | high | mitigate | No new package: aiohttp is already locked (3.14.3) as a dependency of binance-common; the change adds only the direct requirement with a floor and a ceiling; uv lock --check; the diff of uv.lock is reviewed for other changes |
| T-18-62 | Denial of service | no SDK rotation timer, so the 24-hour connection cap drops the stream unnoticed | medium | mitigate | The plan stops unless a project rotation interval is ratified; the supervisor rotates on it; the transport reports close events |
| T-18-SC | Tampering | npm/pip/cargo installs | high | mitigate | Only the conditional promotion of aiohttp, already locked and legitimate (research Package Legitimacy Audit: no new package); no other install |
