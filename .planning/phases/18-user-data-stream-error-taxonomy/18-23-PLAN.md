## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| probe write cases -> Binance Demo (orders, positions) | These cases send real Demo orders: far limit orders, small marketable entries, reduce-only conditional legs |
| recorded observation -> conclusion | A case that acts or concludes on a premise the exchange rejected would record a false fact |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-18-55 | Tampering | orders larger than the owner approved | high | mitigate | One shared order-bound helper refuses any quantity above the approved one or any notional above the approved cap before sending (single exception: the owner-approved market_lot_probe_quantity); validated in tests for every write case |
| T-18-72 | Tampering | a dependent case (orphan, full fill, below-notional, triggered lifecycle) sending orders or recording a conclusion on a carrier or leg the exchange rejected | medium | mitigate | Dependent cases read the premise outcome from the run recorder and record NOT_OBSERVED with the reason otherwise; both branches of every dependent case are covered by scripted tests; no retry exists in any case |
| T-18-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed or changed in this plan |
</threat_model>
