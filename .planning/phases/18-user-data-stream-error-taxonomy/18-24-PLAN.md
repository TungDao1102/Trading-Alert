<objective>
Give the synthetic user-data wire frames their file form (D-21): six JSON fixtures generated from the frame builders of plan 18-03, a README that labels each one SYNTHETIC_FROM_SDK_MODEL, and a test that proves every fixture equals its builder, parses to the expected typed event, folds through the unchanged idempotent `fold_fills` where it carries a trade, and is listed in the README exactly. Output: the README, the six fixture files and `tests/test_userdata_fixtures.py`.

Tracer note: Task 1 is the tracer: one fixture (the TRADE frame) goes from file to typed event to FillEvent to folded view, with the README rule, before the other five are added.

Machine rule: no network. The frames are synthetic, built from the field set of the installed SDK models by plan 18-03's builders; nothing is recorded from Binance here.

Out of scope: the parsers, the event types and the frame builders (plan 18-03; not edited here), RECORDED_DEMO frames and the recorded-frame tests (plan 18-21).
</objective>
