<objective>
Build the pure pre-placement refusals of criterion 2 (former Phase 15 live-price check): price crossed the stop or left the zone, remaining validity too short, another plan or position on the symbol, plan status or invalidation rule says invalid, hedge mode. Every check is a pure function of injected values returning a reason code or None; a composite evaluates them first-failure-wins. The manager (plan 19-13) performs the adapter reads and passes the values, and every refusal happens before the approval is consumed.

Purpose: D-05, D-06 (pure staleness part), D-07 (unset limit refuses), D-08 (distinct invalidation code), D-09 (deny-list status), D-14 (hedge refused), RISK-04. GTD as exchange backstop needs goodTillDate > now + 600 s with second precision (research B6): good_till_date_ms is computed here, the adapter sends it (plan 19-05), the manager uses it (plan 19-15).

Recorded, not decided: research Q2 (only mark price is read; last price via /fapi/v1/ticker/price is deliberately not added because the stop triggers on MARK_PRICE, D037), Q6 (the latest closed bar close is a required injected value; its producer is Phase 24), Q7 (the exchange open-order snapshot is the authority; an intent-store cross-check needs a new store query and is not built), O-04 (numbers).

Output: src/execution/pre_placement.py and its test grid.
</objective>
