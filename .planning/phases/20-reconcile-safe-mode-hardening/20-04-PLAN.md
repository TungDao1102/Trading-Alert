<objective>
Make the pure compare see what it is blind to (criterion 1, F-701; D-01, D-01a, D-02, D-03, D-05, D-07): a reverse pass over exchange orders, a per-symbol signed bound check, a STOP requirement for every open position, an entry-aware orphan rule, duplicate-id detection and Hedge-row refusal. Pure transform with TDD: the new kinds are proven with dict/dataclass fixtures before any loop exists (plan 20-12 composes it).

Purpose: every later reconcile decision (SAFE_MODE, sweep, delegate, alert) is driven by these kinds.

The bound check is deliberately a bound (D-01a): `abs(exchange) <= intended_quantity` and sign = plan side. It is per symbol, because a One-way position is the symbol's exposure; it equals a per-plan check only while the Phase 19 one-plan-per-symbol pre-placement rule holds. D-01a is a review resolution the owner has not yet confirmed (O-F); this plan implements its strictly fail-closed reading (it only adds divergences) BEFORE the owner is asked, so its SUMMARY must carry executed test evidence for the bound check (sign/direction for both sides, the bound abs(exchange) <= intended_quantity, fail closed when local data is missing, the over-fill-below-bound limit) that plan 20-10's O-F checkpoint cites; acceptance of D-01a there is a policy acceptance, not a substitute for that evidence. The owner-gated policy (dedicated SAFE_MODE reason, local ownership source) is plan 20-20.
