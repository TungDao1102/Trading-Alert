<objective>
Make risk-reducing actions independent of the journal and the database (criterion 3, D-16, F-702): act first, keep the audit record in a local durable spill when the journal is down, replay it later. Today disable() journals before flipping, and expire_pending_entry / cancel_untriggered_protectives journal a pre-image before the cancel, so a DB outage keeps live orders enabled and issues no cancel (D051 item h).

Purpose: the operator and the coordinator can always reduce risk; the audit trail catches up.

Scope: the four controls named by D-16. The emergency_manual_close step ORDER (cancel protectives only after two flat reads) is plan 20-11; post-cancel verification (-2011, D-17) is plan 20-11. The coordinator sweep calls cancel_untriggered_protectives and inherits the act-first behavior. The spill-backed restart rebuild is plan 20-19.

Executor rules: `codegraph explore "LiveEnablementController.disable expire_pending_entry cancel_untriggered_protectives emergency_manual_close replace_with_retry PgJournalStore"` first; run only this plan's tests; src/execution/manager.py and src/execution/enablement.py are CRLF-sensitive (edit bytes-aware); stage explicit paths; commit trailer = the model that did the work.
</objective>
