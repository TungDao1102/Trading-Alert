<objective>
Close the EXEC-06 gaps (D-26; research Pattern 7): there is no "close strategy position on explicit action" and no "re-place protection" control in code today (emergency_manual_close only cancels, and since plan 20-11 never cancels a protecting stop). Both new controls go through the protection coordinator so a human action follows the same rules as the automatic flow (D-06, D-16).

Purpose: the operator can flatten a strategy position, or trigger the system's own protection rule for it, without the exchange UI and without ever loosening risk or re-placing a stop that D077 forbids.

Decision (revision 2; owner direction 1 on the D-26/D077 conflict, relayed by the orchestrator on 2026-10-21): operator_protect_position STAYS as the EXEC-06 "re-place protection" control, but it has no placement code of its own. In the never-confirmed branch it runs the coordinator's own per-plan step for that plan once, under the step lock; in a confirmed state it only adopts an ACTIVE stop; in the stop-lost branch, in CLOSE_REQUIRED / CLOSE_FAILED and when the stop history is unknown it refuses with nothing sent. Why not adopt-only: D-26 and EXEC-06 name a "re-place protection" control, and an adopt-only control would leave that item unmet. Why this does not duplicate the coordinator's B2/B3 same-id re-place: there is one placement path (the coordinator's), one step lock and one absence-proof rule, so the operator call can only cause a placement that the coordinator's next cadence step would make anyway (it removes the wait for the cadence, a Phase 24 number) and it cannot extend the max_unprotected_ms window (the same step escalates at the deadline). Coupling, recorded in the SUMMARY: the basis of that B2/B3 re-place is listed as an owner confirm-or-reject item at O-A (plan 20-26); if the owner rejects it, the automatic path and this control change together in a gap plan, because they are one path.

Executor rules: `codegraph explore "_enter_close_required _close_flow _place_stop derive_algo_client_id MarketEmergencyCloser.close_position emergency_manual_close safe_mode_freeze"` first; run only this plan's tests; protection.py and manager.py are CRLF-sensitive (edit bytes-aware); stage explicit paths; commit trailer = the model that did the work.
</objective>
