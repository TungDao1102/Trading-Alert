<objective>
Implement the owner's Q3 decision (option (b), emergency close only; D-21): when exchangeInfo cannot be read during an emergency close, use the last validated MARKET_LOT_SIZE filters flagged stale; never for a new entry; with none, guess nothing and stay fail-closed.

Purpose: an emergency close is not blocked by a transient exchangeInfo failure, and no entry ever trades on stale filters.

The periodic refresh (reconcile.lot_filter_refresh_interval_ms) is wired into the tick by plan 20-21; this plan provides refresh_if_due.

Executor rules: `codegraph explore "MarketEmergencyCloser.close_position symbol_lot_filters LotFilters next_close_part plan_close_parts PgPlanConstraintSnapshotStore"` first; run only this plan's tests; `alembic upgrade head` only; emergency_close.py is CRLF-sensitive (edit bytes-aware); stage explicit paths; commit trailer = the model that did the work.
</objective>
