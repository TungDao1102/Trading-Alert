<objective>
The live risk-input builder: the single place that assembles what `execute_approved_plan` takes as `risk_kwargs` today from a caller (account state, open positions, daily loss, thresholds) out of the Phase 21 live sources, plus the mapping from terminal plan states to reservation release reasons.

Purpose: criterion 1 ("sizing uses Binance-canonical equity, never a caller-supplied constant") and criterion 3 (caps count resting entries and approved-but-unplaced plans) meet the manager here; `decide_placement` re-judges with the same values. Phase 24 composes it; Phase 21 proves it, including parity with the backtest inputs.
Output: `src/execution/live_risk_inputs.py` and two test files.

Executor rules (AGENTS.md): run `codegraph explore "execute_approved_plan evaluate_risk check_portfolio open_positions_for_risk Ledger.start register_exposure"` before Grep/Read; run only this plan's tests and the gate files; stage explicit paths only; the commit trailer names the model that did the work; never push or merge. The module reads no wall clock and imports no adapter, SDK or persistence module; it does not change `execute_approved_plan` or `decide_placement`.
</objective>
