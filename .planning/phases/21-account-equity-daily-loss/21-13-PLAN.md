<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stream fills and REST rows -> day loss | two untrusted exchange sources decide the daily stop |
| persisted day state -> restart | stored rows decide whether trading may resume after a restart |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-28 | Repudiation | lost frames during a gap hide a loss | high | mitigate | Every ACCOUNT_UPDATE or gap marks the loss unknown until a REST backfill completes after it (generation check); the recorded SL close is proven to reach the loss |
| T-21-29 | Tampering | a restart resetting the day or moving the base | high | mitigate | open_day returns the stored row; the latch is read back; a missing state with exposure blocks (DAY_STATE_MISSING) instead of opening a fresh day |
| T-21-30 | Denial of service | REST reads during a 429/418 pause | medium | mitigate | A refused read leaves the loss unknown (NO_TRADE); no retry or sleep in the service; reads go through the gated adapter |
| T-21-SC | Tampering | dependency set (pyproject.toml, uv.lock) | low | mitigate | No package is added; `git diff --exit-code -- pyproject.toml uv.lock` exits 0 |
</threat_model>
