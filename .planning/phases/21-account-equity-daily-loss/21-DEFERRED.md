# Phase 21 deferred register

Written by plan 21-14 on 2026-10-23. It lists what Phase 21 deliberately did NOT build or decide, and what only the owner can decide or run, each with its owner phase or owner decision. It is the Phase 21 counterpart of `20-DEFERRED.md`; the owner's answers and the open items of this phase are in `21-OWNER-DECISIONS.md`, which this file cites and does not reinterpret.

Evidence in Phase 21 is executed tests with fakes (scripted account readers, an in-memory day-state store, the real Binance adapter over a fake SDK serving recorded Demo payloads) and a local PostgreSQL for the `*_pg.py` files. This machine reached Binance only through earlier recorded Demo captures. Nothing built in Phase 21 is wired in a running process: no live equity source, day risk service, daily stop or reservation call is started by any entry point before Phase 24. No requirement is marked complete by this phase. `docs/DECISIONS.md` has no Phase 21 row. Demo facts carry "demo-observed, not mainnet" (D-22). Labels: `[DOC]` a documentation fix, `[DESIGN]` built and tested with fakes only, `[NOT_TESTED]` no test or probe exists.
