<objective>
Compose the Phase 22 guard: one object, one call, one fixed order, the first refusal wins.

Purpose: criteria 1 to 4 are only useful if a plan cannot reach the exchange without passing all of them in the right order (A7): the mode of the account first (so nothing is mutated on a hedge or multi-asset account), then the configuration (which fixes the leverage every later number depends on), then the liquidation check (which needs the verified leverage and the exchange brackets), then the margin check (which needs the verified leverage for the initial margin and a fresh reading). The guard is a library: the manager calls it behind a required port (plan 22-15); nothing is composed into a running process (D-17); live placement stays disabled. Backtest parity (D-15): the backtest has no margin or liquidation model, so these are live-only gates like the Phase 21 equity age; sizing and quantization are unchanged (RISK-01): the guard judges the already-sized quantity at the already-snapped limit price and never alters either.
