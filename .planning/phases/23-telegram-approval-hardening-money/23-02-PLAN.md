<objective>
Build the money block once, in the risk layer, from the risk pipeline output (ROADMAP Phase 23 criterion 2, F-015; CONTEXT D-13; orchestrator resolution 1 and 2).

Purpose: the research found that notional, margin, gross and net loss at SL and gross and net profit at each TP are produced nowhere today (profit at TP not at all). Criterion 2 says "all values come from the risk pipeline output, never recomputed": the reading recorded here (and to be confirmed by the owner, plan 23-13 register) is that the values are computed ONCE by this pure builder at plan-issue time, stored with the PENDING approval rows (plan 23-04, `approvals.money_json`), and only formatted by the Telegram code (plan 23-09). The builder is mode-agnostic; SHADOW text stays unchanged in this phase (resolution 1: showing it in SHADOW is an owner question).

Choices made here (Claude's discretion, D-13; listed for the owner):
- Equity source labels (resolution 2): `EQUITY_SOURCE_ACCOUNT_LIVE = "ACCOUNT_LIVE:min(totalWalletBalance,totalMarginBalance)"` (D086 basis) and `EQUITY_SOURCE_PAPER_CONFIG = "PAPER_CONFIG:initial_equity"`, always carried with the observation time.
- Leverage source labels: `LEVERAGE_SOURCE_CONSTRAINT_SNAPSHOT = "PLAN_CONSTRAINT_SNAPSHOT:verified_leverage"` (Phase 22) and `LEVERAGE_SOURCE_PAPER_CONFIG = "PAPER_CONFIG:target_leverage"` (its value is Phase 22 owner item O-1; never invented here).
- Profit at each TP is per leg: leg quantity = quantity x the plan's TP fraction (the fractions the SHADOW alert already shows, TP1_QUANTITY_FRACTION and its complement), gross = leg quantity x favourable distance, net = gross - leg quantity x per_unit_round_trip_cost(entry, exit at the TP price). It is an estimate: the live TP sizing floors the TP1 leg to the step size (Phase 19), so a real leg can be smaller.
- The stored form carries `"schema": "money-at-stake/1"` so a later change of the block is a new schema tag, not a silent reinterpretation.

Output: `src/risk/money_at_stake.py`, its tests, and the module added to the no-float guard list.
