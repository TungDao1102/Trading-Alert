<objective>
Build the one seam that takes synchronous PostgreSQL and file store calls off the event loop (D-25, G4-040) and move the paper runtime's on-loop `expire_due` call behind it (P16R-03), before any live store call is composed.

Purpose: every live store call (approval decisions with the Phase 21 reservation under a FOR UPDATE lock, journal writes, intent writes, order and position snapshots) would otherwise block the loop that also runs the Telegram runner, the stream and the protection step (research P-1). Research P-2 measured that the default executor reorders concurrent writes, so ordered writes need one dedicated worker. The module lives in `src/ops`, outside `src/execution` and `src/live`, because the SHADOW isolation closure test bans those packages (C-11).
