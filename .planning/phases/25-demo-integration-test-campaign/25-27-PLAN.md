## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local spill -> journal | files written by the process during an outage become journal rows that the sweep and the restart trust |
| journal -> reservation release / restart | the plan's end row decides whether a reservation is released and whether a plan is rebuilt |

| T-25-61 | Tampering | a replay overwriting or contradicting a stored row | high | mitigate | `replay_spill` never overwrites; a conflict or corrupt file enters SAFE_MODE RESTORE_INCONSISTENT and keeps the file |
