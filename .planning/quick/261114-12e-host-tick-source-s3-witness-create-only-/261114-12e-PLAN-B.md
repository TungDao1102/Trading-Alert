## Host design (fixed by this plan)

**Script `deploy/freeze-witness.sh`.** It starts with `#!/usr/bin/env bash` and `set -Eeuo pipefail`, sources `lib.sh`, exports `MSYS_NO_PATHCONV=1` like heartbeat.sh, and carries a usage header. Its modes:
- no mode flag: one tick;
- `--set-credential`: as root, read the credential from stdin;
- `--install-timer --soak-env-file PATH`: as root;
- `--dry-run` with any mode;
- `-h | --help`.

A mode combination it does not know, or an unknown flag, exits 2.

Constants:
- credential name `freeze-witness`;
- default credential file `/etc/trading/freeze-witness.conf`, mode 0600, read through `p`;
- units `trading-soak-freeze-witness.service` and `trading-soak-freeze-witness.timer`;
- step timeout `FREEZE_WITNESS_STEP_TIMEOUT_SECONDS`, default 120. Label it as a PLACEHOLDER transport bound so a hung docker or curl cannot hang the oneshot. It is never an evidence value: the grace of 1800 s is the only lateness rule.

**Credential format.** Exactly five `key=value` lines, each key once, no other line:

| Key | Allowed value |
|-----|---------------|
| `bucket_url` | `^https://[A-Za-z0-9][A-Za-z0-9.-]*(:[0-9]{1,5})?(/[A-Za-z0-9][A-Za-z0-9._-]*)?$` (virtual-hosted, or path-style with the bucket as the one path segment) |
| `region` | `^[a-z0-9-]{2,32}$` |
| `witness_prefix` | segments of `[A-Za-z0-9._-]+` joined by `/`, no `.` or `..` segment |
| `access_key_id` | `^[A-Za-z0-9]{16,128}$` |
| `secret_access_key` | `^[A-Za-z0-9/+=]{16,128}$` (no quote or backslash, so it is safe inside the curl config string) |

Any deviation exits 4 with a fixed message that never shows a value. Values live in non-exported shell variables.

**One tick.** Steps in order; the exit code on failure is in brackets.
1. Refuse xtrace [2].
2. Load the credential from `$CREDENTIALS_DIRECTORY/freeze-witness` only, with no file fallback [4].
3. `FREEZE_WITNESS_SCHEDULE` must match `^([0-9]|[1-5][0-9]) \* \* \* \*$` [2]. Take the minute M from it.
4. Compute now from `date -u +%s` and the slot epoch = now − ((now − M·60) mod 3600). The slot text is `date -u -d @<slot epoch> +%Y%m%dT%H%MZ`. It is a key label only: the evaluator rejects a label that differs from the witness slot.
5. The tick id is 32 lowercase hex characters from `/dev/urandom` (for example `od -An -N16 -tx1`, with spaces removed).
6. The container id is the single line of `bash deploy/compose-soak.sh ps -q paper`, matching `^[0-9a-f]{12,64}$` [1].
7. The image is `docker inspect --format '{{.Image}}' <cid>`, matching `^sha256:[0-9a-f]{64}$` [1].
8. The scratch directory is `mktemp -d` under `${RUNTIME_DIRECTORY:-${TMPDIR:-/tmp}}`, removed by an EXIT trap.
9. Run `docker cp <cid>:/app/logs/paper/pinned_epoch.json <scratch>/pinned_epoch.json` [1]. The epoch id is read from that file with the pattern `"epoch_id": *"([A-Za-z0-9._-]{1,128})"` [1].
10. Run `timeout <T> docker run --rm --network none --read-only --cap-drop ALL --security-opt no-new-privileges --user "$(id -u):$(id -g)" --mount type=bind,src=<scratch>,dst=/scratch -e PAPER_TICK_SOURCE=host -e PAPER_TICK_ID=<id> -e "PAPER_EVENT_SCHEDULE=<cron>" <image> /app/.venv/bin/python -m src.paper.freeze --check --from-allowlist --pinned-state /scratch/pinned_epoch.json --diff-log /scratch/registry_diff.jsonl --registry-root /app/params`. Keep the CLI exit code.
11. The line file must exist [1]. It must hold exactly one newline, as its last byte, and at most 4096 bytes [5]. It must contain `"source":"host"`, `"tick_id":"<id>"` and `"schedule":"<cron>"` [5; message: the image predates the host tick source (plan A) or the line is not a host line; nothing uploaded]. Its outcome must be one of `"outcome":"clean"`, `"outcome":"REGISTRY_DIFF"` or `"outcome":"SKIPPED"` [5].
12. The key is `<witness_prefix>/<epoch>/<slot>-<id>.jsonl`. The hash is the `sha256sum` of the line file.
13. Upload once, with no retry and never without the create-only header. Pipe `printf 'url = "%s/%s"\nuser = "%s:%s"\n'` (a builtin, so not in any argv) into `curl --silent --fail --proto =https --max-time <T> --aws-sigv4 aws:amz:<region>:s3 --upload-file <line file> -H 'If-None-Match: *' -H 'x-amz-content-sha256: <sha>' --output /dev/null --write-out '%{http_code}' --config -`, with stderr discarded. A non-zero curl exit [6] logs `witness: upload not accepted (curl exit N, HTTP C); this host tick does not count and is never re-sent`. For HTTP 412 it adds `an object already exists at this key; nothing was replaced`.
14. Log `witness: created <epoch>/<slot>-<id>.jsonl (<outcome>)`. The bucket URL, the prefix value and the credential are never logged. Exit 0 for clean or SKIPPED, 3 for REGISTRY_DIFF.

Under `--dry-run` the tick:
- still validates the credential and the schedule;
- prints the planned docker steps through `run` with placeholders, and `+ upload (create-only, If-None-Match: *): <epoch_id>/<slot>-<id>.jsonl; URL and credential not shown`;
- runs no docker and no curl.

The only docker verbs are `compose ... ps`, `inspect`, `cp` (from the container) and `run --rm`. The script never stops, restarts, execs into or removes the paper container, and never writes the runtime's pin.

**`--set-credential`.** Requires root unless `TRADING_ROOT_PREFIX` is set (the test seam). Reads exactly five lines from stdin with `read -rs`, without echo (it prints a prompt only on a tty), validates them, and writes them with `write_if_changed <prefixed file> <content> 0600`, then `chmod 0600`. It never shows a value. Invalid input exits 4 and writes nothing.

**`--install-timer --soak-env-file PATH`.**
- Requires root. PATH must match the `UNIT_PATH_PATTERN` of heartbeat.sh [2].
- The credential file and the soak env file must exist; under `--dry-run` a missing file is only a warning.
- Read `$REPO_ROOT/.github/workflows/paper_freeze_check.yml`. It must hold exactly one `cron: "M * * * *"` item of the hourly form; otherwise die.
- Substitute `@TRADING_DIR@`, `@CREDENTIAL_FILE@`, `@SOAK_ENV_FILE@`, `@CRON_MINUTE@` (two digits) and `@SCHEDULE@`, then write both units with `write_if_changed`.
- Run `systemctl daemon-reload` when a unit changed, then `systemctl enable --now trading-soak-freeze-witness.timer`, and restart the timer when it changed.

**Exit codes.**

| Code | Meaning |
|------|---------|
| 0 | uploaded, clean or SKIPPED; or a dry run |
| 1 | the tick could not run: no paper container, no pin, no line |
| 2 | usage, an invalid schedule, or xtrace |
| 3 | uploaded REGISTRY_DIFF |
| 4 | the credential is missing or invalid |
| 5 | the line does not carry the host identity |
| 6 | the upload was refused or failed |
