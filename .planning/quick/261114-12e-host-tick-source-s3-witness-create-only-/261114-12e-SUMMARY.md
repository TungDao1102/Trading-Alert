### Plan clarifications (no code deviation)

1. **Identical-bytes DUPLICATE has no standalone test.** The Design says a tick id or the SHA-256 of the bytes that appears in more than one host tick makes each DUPLICATE. Both are implemented (`_host_duplicates`, `hashlib`). A test with identical bytes at two different keys cannot reach check 7 with a real CLI line: identical bytes carry one tick id and one `checked_at_utc`, so the second key either has a different tick id (WRONG_SOURCE, check 3) or a different slot (OUT_OF_SLOT, check 6). The shared-tick-id case is tested.
2. **`HostTick.data` of a non-UTF-8 object is None in the exporter**, so the exporter judges exactly what the loader later reads (`text` null -> `data` None -> UNREADABLE and a break).
3. **Local listing parser in the exporter.** `collect_host_witness` parses the listing with its own strict parser (keeping the raw ModTime text so a sub-microsecond change between the two listings is also caught) instead of importing the loader's private function, to keep Task 3 inside its file list.
4. **Line endings.** The working copies of the touched source files are CRLF under the repository's autocrlf; edits preserved that (the index is LF, so diffs are unaffected).
