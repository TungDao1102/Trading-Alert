# Conventions

- Strict typing (mypy strict, `disallow_untyped_defs`); Decimal for exchange-sensitive values via `src/core/_decimal.py` (`_add/_sub/_mul/_div`).
- Domain/strategy/backtest packages must not import Polars, FastAPI, SQLAlchemy ORM models; adapters own SDK/data-frame work.
- Enum values (e.g. `RejectionReason`) come from `docs/GLOSSARY.md` §9 first, then code; enum member counts are pinned in tests.
- Parameter sets: new versioned TOML under `params/**`; never edit existing; hashes pinned in `tests/test_registry.py` etc.
- Rejections/errors: project exceptions, fail closed, never silent padding.
- Fixtures: golden expected outputs must be hand-derived, not generated by code under test; regression snapshots labeled as such.
- Tests never hit Binance/Telegram; use recorded fixtures and respx.
- Commit style: `docs(NN): ...`, `fix(ci): ...`, `test(uat): ...`; planning artifacts committed via `gsd-tools query commit`.
- Work flows through GSD commands (`/gsd-discuss-phase`, `/gsd-plan-phase`, `/gsd-execute-phase`, `/gsd-quick`) per AGENTS.md.
